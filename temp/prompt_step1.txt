# 역할 및 프로젝트 정의
당신은 iOS 트윅 전문 개발 실무자입니다. 오케스트레이터의 감독 하에 아래 요구사항에 맞추어 `SiriGemini` 트윅의 1단계 소스코드 구현 작업을 수행하세요.

## [1단계: 소스코드 스켈레톤 및 핵심 로직 구현]
* **작업 디렉터리:** `D:\llama agent\tweak\sirigemini\src\`
* **타겟 환경:** iOS 18.7.1 / RootHide (Dopamine 3) / `iphoneos-arm64e`
* **핵심 컨셉:** 
  기존 유료 API 키 방식 대신, Google 계정 웹 로그인(WebView 쿠키 `__Secure-1PSID`, `__Secure-1PSIDTS`)을 활용하여 Siri 요청을 Gemini Web과 연동하는 트윅입니다.

## 구현 상세:
1. `src/Tweak.x`:
   - `%hook AFConnection`: Siri 음성 인식 콜백 `_tellSpeechDelegateSpeechRecognized:` 훅.
   - 키워드나 토글 활성화 시 기존 음성 처리 가로채고 GeminiWebClient 호출.
   - `%hook SAUIAssistantUtteranceView` (또는 `AFSpeechToken` / `SiriUI` 관련 훅): Gemini 응답 텍스트를 Siri 발화 및 화면에 표시.
2. `src/GeminiWebClient.h`, `src/GeminiWebClient.m`:
   - `/var/mobile/Library/Preferences/com.csw.sirigemini.plist`에서 로그인 쿠키 읽기.
   - Gemini 웹 엔드포인트(`https://gemini.google.com`)와 비동기 통신 (`NSURLSession`).
   - 질문 전송 및 응답 텍스트 추출 완료 후 콜백 실행.
3. `src/Preferences/` (PreferenceBundle):
   - `RootListController`: 트윅 On/Off 토글, "Google 로그인" 버튼.
   - `LoginWebViewController`: `WKWebView`로 `https://accounts.google.com` / `https://gemini.google.com` 띄우기.
   - 로그인 완료 시 `WKWebsiteDataStore`의 `WKHTTPCookieStore`에서 `__Secure-1PSID`, `__Secure-1PSIDTS` 쿠키를 추출하여 plist에 저장.
4. `src/Makefile`:
   - RootHide 규격: `THEOS_PACKAGE_SCHEME = roothide`, `ARCHS = arm64 arm64e`.
   - Tweak 및 PreferenceBundle 빌드 타겟 포함.
5. `src/layout/DEBIAN/control`:
   - `Package: com.csw.sirigemini`
   - `Version: 1.0.0`
   - `Architecture: iphoneos-arm64e`

위 소스 파일들을 `D:\llama agent\tweak\sirigemini\src\` 및 하위 폴더에 직접 작성하고, 생성된 파일 목록과 각 컴포넌트의 구현 내용을 6대 필수 상세 보고 양식(1~3번 항목 중심)에 맞춰 명확히 보고하세요.
