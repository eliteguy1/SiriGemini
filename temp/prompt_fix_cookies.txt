# 긴급 개선 지시: Google 로그인 WebView 쿠키 추출 실패 문제 해결

## 1. 문제 현상 및 원인 분석
사용자가 iOS 기기에서 트윅 설치 후 Settings -> SiriGemini -> "Google 로그인" 화면에서 로그인을 시도했으나,
`"로그인 쿠키를 찾지 못했습니다. webview에서 구글 로그인을 먼저 완료하세요."` 얼럿이 발생함.

### 핵심 원인:
1. **초기 로드 URL 불일치**:
   - `LoginWebViewController.m`이 `https://accounts.google.com/`을 로드하여 사용자가 계정 관리 화면에 머무름.
   - `__Secure-1PSIDTS` 등 Gemini 관련 쿠키는 `https://gemini.google.com/`에 접속해야 발급됨.
2. **쿠키 검사 조건이 지나치게 엄격함**:
   - `psid.length > 0 && psidts.length > 0` 둘 다 동시에 엄격히 요구함.
   - 일부 Google 계정/브라우저 세션에선 `__Secure-1PSIDTS` 대신 `__Secure-1PSID`, `__Secure-3PSID`, `SID` 등이 메인 인증 쿠키로 사용됨.
3. **HTTP 요청 시 전체 쿠키 문자열 부재**:
   - Gemini Web RPC 통신 시 2개 쿠키뿐만 아니라 Google 세션의 전체 쿠키(`Cookie: SID=...; __Secure-1PSID=...; ...`)가 헤더에 들어가야 401/403 없이 안정적으로 동작함.

---

## 2. 구체적 수정 요구사항

### A. `src/Preferences/LoginWebViewController.m`:
1. **초기 URL을 `https://gemini.google.com/`으로 변경**:
   - 미로그인 시 Google 로그인 화면으로 자동 이동하며, 로그인 완료 시 Gemini 홈(`https://gemini.google.com/app` 등)으로 자동 진입함.
   - `webView:didFinishNavigation:`에서 현재 URL이 `gemini.google.com`에 도달했는지 확인하고 로그 출력.
2. **쿠키 추출 및 저장 로직 전면 개선 (`saveCookiesAndFinish`)**:
   - `[store getAllCookies:]` 콜백에서 모든 쿠키를 순회.
   - `.google.com` 및 `gemini.google.com` 도메인에 해당하는 쿠키들을 추출.
   - `SID`, `__Secure-1PSID`, `__Secure-3PSID`, `__Secure-1PSIDTS` 중 하나 이상이 존재하면 로그인 성공으로 판정.
   - 모든 쿠키를 `name=value` 형태의 세미콜론 구분자 문자열(`allCookiesString`)로 결합하여 `prefs[@"cookieString"]`에 저장.
   - 기존 호환성을 위해 `prefs[kCookie1PSID] = psid;`, `prefs[kCookie1PSIDTS] = psidts;`도 함께 저장.
   - 성공 얼럿 메시지에 발견된 쿠키 개수와 핵심 쿠키 존재 여부를 상세 표시 (예: `@"Google 로그인 쿠키 저장 완료 (쿠키 %lu개 감지)"`).
   - 실패 시에도 현재 수집된 쿠키 목록(이름들)을 로그와 얼럿에 표시하여 디버깅이 가능하도록 함.

### B. `src/GeminiWebClient.h` 및 `src/GeminiWebClient.m`:
1. `hasLoginCookies` 메소드:
   - `cookieString.length > 0` 또는 `psid.length > 0`이면 YES 반환.
2. `sendQuestion:completion:` 메소드:
   - 요청 생성 시 `cookieString`이 있으면 `[request setValue:cookieString forHTTPHeaderField:@"Cookie"]`로 전체 주입.

### C. macOS VM 동기화 및 재빌드:
1. 로컬 수정된 소스코드 VM(`~/build_sirigemini`)으로 명시적 scp 동기화.
2. `make clean && make package THEOS_PACKAGE_SCHEME=roothide` 실행.
3. 산출물 deb 패키지를 `D:\llama agent\tweak\sirigemini\build\`로 회수.
4. `PROJECT.md` 및 `docs/`에 변경 내역 기록.
