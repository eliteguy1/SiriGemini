# 역할 및 2단계 작업 지시
당신은 iOS 트윅 전문 개발 실무자입니다. 오케스트레이터의 지시에 따라 `SiriGemini` 트윅의 2단계 [macOS VM 동기화 및 RootHide 빌드/컴파일] 작업을 수행하세요.

## [2단계: macOS VM 동기화 및 컴파일/빌드 검증]
* **VM 환경:** VMware macOS (`csw@192.168.1.21`), THEOS: `/Users/csw/theos`, ldid: `/usr/local/bin/ldid`
* **VM 빌드 디렉터리:** `~/build_sirigemini`
* **로컬 소스 경로:** `D:\llama agent\tweak\sirigemini\src\`

## 필수 준수 규칙 (RootHide VM 빌드 프로토콜):
1. **VM 디렉터리 준비 및 파일별/폴더별 명시적 scp 전송 (디렉터리 구조 깨짐 방지)**:
   - `ssh csw@192.168.1.21 "mkdir -p ~/build_sirigemini/layout ~/build_sirigemini/Preferences"`
   - `scp "D:\llama agent\tweak\sirigemini\src\Makefile" csw@192.168.1.21:~/build_sirigemini/Makefile`
   - `scp "D:\llama agent\tweak\sirigemini\src\Tweak.x" csw@192.168.1.21:~/build_sirigemini/Tweak.x`
   - `scp "D:\llama agent\tweak\sirigemini\src\GeminiWebClient.h" csw@192.168.1.21:~/build_sirigemini/GeminiWebClient.h`
   - `scp "D:\llama agent\tweak\sirigemini\src\GeminiWebClient.m" csw@192.168.1.21:~/build_sirigemini/GeminiWebClient.m`
   - `scp "D:\llama agent\tweak\sirigemini\src\SiriGemini.plist" csw@192.168.1.21:~/build_sirigemini/SiriGemini.plist`
   - `scp -r "D:\llama agent\tweak\sirigemini\src\Preferences\*" csw@192.168.1.21:~/build_sirigemini/Preferences/`
   - `scp -r "D:\llama agent\tweak\sirigemini\src\layout\*" csw@192.168.1.21:~/build_sirigemini/layout/`
   - `scp "D:\llama agent\tweak\sirigemini\src\control" csw@192.168.1.21:~/build_sirigemini/control`
2. **DEBIAN 권한 설정 (필수)**:
   - `ssh csw@192.168.1.21 "chmod -R 755 ~/build_sirigemini/layout/DEBIAN"`
3. **RootHide 표준 컴파일 실행**:
   - `ssh csw@192.168.1.21 'source ~/.zshrc && export PATH="/usr/local/bin:$PATH" && cd ~/build_sirigemini && make clean && make package THEOS_PACKAGE_SCHEME=roothide'`
4. **컴파일/빌드 오류 발생 시**:
   - 컴파일러 에러 로그를 분석하여 로컬 소스(`D:\llama agent\tweak\sirigemini\src\`)를 수정하고, 수정한 파일을 VM으로 다시 scp하여 빌드가 통과할 때까지 반복 해결하세요.
5. **빌드 성공 시 산출물 로컬 회수**:
   - 생성된 deb 패키지를 `D:\llama agent\tweak\sirigemini\build\` 디렉터리로 scp 복사하세요.

작업 완료 후 실행한 명령, 발생한 빌드 에러 및 수정 내역, 산출물 정보를 6대 필수 상세 보고 양식에 맞춰 상세히 보고하세요.
